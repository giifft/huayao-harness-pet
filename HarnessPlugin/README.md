# 花妖桌宠 · DeepSeek Harness 插件

越剧《花妖》饭制桌宠，悬浮在 DeepSeek Harness 窗口内。内置 21 款双人、13 款花旦和 4 款小生 Q 版立绘。各角色模式独立记住所选造型。

- **摆放与装扮**。拖动人物或收起后的状态按钮可移动位置，释放后记住落点。聚焦人物后也可用方向键移动。设置里可调尺寸、回到右下角或隐藏。隐藏后从右下角「唤回花妖」恢复。
- **会话联动**。跟随当前 Harness 会话显示思考、读写、检索、等待确认、完成等状态，并选用对应立绘。可关闭状态换姿。工作中暂停主动闲聊、巡场和花瓣。审批仍在 Harness 原界面处理。
- **花台陪伴**。点人物互动，或在「陪伴」中奉茶、签到、查看成就、玩「辨花影」。每日奖励有上限，已完成的互动和签到存于本机。
- **偏好与存档**。花瓣、待机闲聊、待机巡场可分别开关。设置中可导出 JSON，导入会替换当前插件的偏好和陪伴进度。存档没有会话内容、会话 ID 或凭据。插件跟随 Harness 明暗主题并尊重系统减少动态效果设置。

## 安装或启用

1. 在电脑上保存 `huayao-harness-pet-1.1.2.tgz`，保留压缩包。
2. 打开支持第三方插件的 DeepSeek Harness 桌面版，在左侧进入「插件」，选择「添加插件」或「安装第三方插件」。
3. 在包名输入框中粘贴压缩包的**完整本地路径**。macOS 示例为 `/Users/你的用户名/Downloads/huayao-harness-pet-1.1.2.tgz`，Windows 示例为 `C:\Users\你的用户名\Downloads\huayao-harness-pet-1.1.2.tgz`。把示例路径换为你的实际路径。
4. 确认预览里的包名为 `huayao-harness-pet`，安装后选择「立即启用」。若 Harness 提示重启，在重启后继续。
5. 回到聊天页，查看 Harness 窗口右下角。停用或卸载通过同一个「插件」页面操作。

两端使用同一个插件包。插件按 Harness 0.2.2-rc.5 的客户端扩展接口开发，需能安装第三方组合包的 0.2.2 系列桌面版。窗口外的 macOS 原生独立桌宠有自己的安装包。

## 从源码打包

在本项目根目录运行 `bash HarnessPlugin/scripts/build.sh`。需要 Node.js/npm、Python 3 和 Pillow。
